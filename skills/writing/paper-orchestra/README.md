# Paper Orchestra

Writing 的总入口。Paper Orchestra 安排写作阶段与交接，并整合稿件。按需从下层 pack 选用专项技能：

- [Nature](packs/nature/) 处理检索、引文、写作、投稿图件和审稿回复。
- [K-Dense Writing](packs/k-dense-writing/) 负责实验设计、统计、计量及科学可视化。
- [ARS-Codex](packs/ars-codex/) 执行指定的研究规划、深度综述或独立审阅任务。

直接读取分发包时，从 [`paper-orchestra/SKILL.md`](skills/paper-orchestra/SKILL.md) 开始。需要导入时，将 `skills/` 的六个角色目录和所选下层技能同级导入，保留各目录的资源。只处理一个产物时可以点名角色或专项技能。

| 技能 | 任务 |
| --- | --- |
| [paper-orchestra](skills/paper-orchestra/SKILL.md) | 选择角色、组织组稿和核对交接 |
| [paper-orchestra-outline](skills/paper-orchestra-outline/SKILL.md) | 组织论文大纲和主张 |
| [paper-orchestra-literature](skills/paper-orchestra-literature/SKILL.md) | 核查出处、组织引文和综述 |
| [paper-orchestra-figures](skills/paper-orchestra-figures/SKILL.md) | 规划和核对图表、图注及来源 |
| [paper-orchestra-draft](skills/paper-orchestra-draft/SKILL.md) | 起草或整合指定章节 |
| [paper-orchestra-review](skills/paper-orchestra-review/SKILL.md) | 审阅论证、准备回复和返修 |
