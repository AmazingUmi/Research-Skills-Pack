# 核对文献与撰写综述

按用户需要做定向找出处、探索并综合研究脉络、核查稿件现有引文，或写指定的引言与相关工作。收到一个句子的核查任务时，只针对该陈述检索和交付。

## 接收材料

- **目标与范围** — 论文主题、目标章节、领域或语言、日期边界、引用格式。需要区分一个术语首次提出、同名方法版本，还是哪项结果最早公开时，记录具体判据和时间口径。
- **拟写主张** — 原句、已有主张 ID、现有引文键与候选资料。附上能界定主张的研究材料，例如比较条件、样本范围、概念定义或文本版本。
- **已有计划** — 大纲中的引言方向、方法分组或学术争论，以及需要核实的定向引文。若涉及直接比较，以实际研究记录确认参与对象和评价条件。

## 工作步骤

1. **把任务分组。** 探索任务用于了解研究背景、方法、学术分歧和已有证据的边界。定向任务用于定位给定概念、文本、数据源、指标或方法的原始出处，或核查某一条陈述。任务保留章节和主张 ID，按具体对象与要核实的事实编写检索词。
2. **先发现候选。** 定向查找优先检索完整标题、对象名、作者或版本，也可沿引文回溯原始资料。探索检索组合领域词、方法词、材料类型或比较条件，覆盖与问题相关的不同立场。合并重复查询，记录保留理由。用检索摘要或模型推荐定位原件，再按实际取得的材料进行核查。
3. **核验书目身份。** 对照原始出版物、出版社或期刊会议页面、可信预印本记录、档案或图书目录，确认标题、作者、年份、出处和适用的稳定标识。识别同一工作的多个版本或同名不同资料。复用稿件已有引文键，记录实际核读的版本。日期精度不足时单独标明。
4. **核验主张与来源。** 逐条定位章节、页、图、表或原始资料段落。区分来源报告的发现、原作者的假设、跨文献归纳与当前研究得到的结果。注明核读层级，例如原件全文、节选、摘要或书目记录。书目核验确立条目身份，具体结论还要与原件的定义、措辞和适用条件对应。
5. **记录限制或反证。** 源材料逐项对应结论时标已支持。正文暂不可访问、版本冲突或出处未确定时保留待核或冲突，并可改查其他可访问的原始版本、发布机构或附录。材料仍不足时列出缺证据的部分和可保留的较窄表述。判断最早记载或首创时，明确检索覆盖、时间边界与判定标准，按能查到的证据限定范围。
6. **组装引用与写作材料。** 将可用引文键回填到相关小节及主张，标出单篇来源支持的范围。BibTeX 使用核验的书目信息，检查键的唯一性和正文引用能否找到条目。选择适合支持当前论证的来源。
7. **按授权生成指定正文。** 引言组织背景、研究问题、贡献与适用范围。相关工作按问题、方法、材料或争论组织，明确不同来源的假设、证据与结论边界。本文的直接比较以实际研究为准。改稿只处理用户指定的部分，沿用其余模板设置。

## 交付与验收

| 用户请求 | 最小交付 |
| --- | --- |
| 给一句话找可靠出处 | 一条主张证据记录，含原句、状态、来源、位置和所支持的范围 |
| 给若干概念补齐引用 | 可引用条目、稳定引用键、应配在哪一节或哪条主张、待补来源 |
| 核查已有引文 | 逐条核对表、与原句不匹配的部分、最小改写方案 |
| 写相关工作或引言 | 输出指定章节、正文引用和完整出处。另附会影响稿件判断的未决项 |
| 把成果交给正文角色 | 引文表或 BibTeX、引用键到主张的映射、未核实项和实际核读版本 |

逐条核对关键引文的存在性与支持范围。主张状态为已支持、待核、缺证据或冲突。表述语气与证据状态一致。文献中提到的观点或方法与本文实际纳入的比较分别记录。多角色协作按[交接约定](../paper-orchestra/references/handoff.md)传递这些字段。

### 单句核查示例

用户请核对一句话：“某文首次提出了这一术语。”先核对版本、原文措辞和出版日期，再循引文检索更早的同义用法。若现有证据只确认它在某篇文章中出现，可以按下表示例交付。

| 主张 ID | 书目身份 | 支持范围 | 核验状态与建议 |
| --- | --- | --- | --- |
| `C-01` | 已核实文章版本及日期，附原件链接 | 指定页明确使用该术语，尚未查清是否有更早记录 | 将“首次提出”记待核。可写“该文使用了这一术语”，附确切页码 |

这是核查输出的结构示意。真实执行时替换为用户给出的论文身份和准确节页。

## 与上游 PaperOrchestra 的对应

- 上游把 `search_directions`、`limitation_search_queries` 和 `citation_hints` 转成本节任务，然后按章节与查询文本去重。用 Gemini 和 Google Search 并行找候选，再串行调用 Semantic Scholar 补齐并核验元数据。原代码以规范化标题去重，会排除未匹配、截止日期外或缺少摘要的候选。 [检索调度][lit-search] · [候选入库][lit-register]
- 上游发现提示词针对定向任务请求一个候选，探索任务请求 10–15 个。质量依赖候选相关性与核验结果。当前角色可以用可访问的官方原件和索引互证，建议数无需复刻。 [候选提示词][lit-discovery]
- 上游将候选引文键按章节回填 `outline_v1.json`，同时写出 `references.bib`、`citation_map.json` 以及包含 Introduction 和 Related Work 的 `updated_template.tex`。源码把两节引文覆盖量写进提示词，当前角色以具体主张是否得到证据支持作为采用依据。 [大纲回填][lit-inject] · [写作与保存实现][lit-output]
