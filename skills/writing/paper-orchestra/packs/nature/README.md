# Nature Skills

文献检索与阅读、论文写作与润色、引用核验、审稿、科研图表与演示材料。

从本 pack 的 `skills/` 选择完整的技能目录，复制到 Agent 支持的技能位置。读取同级引用的技能需要同时导入 `nature-shared`。完整导入时保留技能间的相对位置，并可随包查看 `docs/` 下的 Paper Card 教程。

`researchwrite` 是研究计划和项目申请书的入口。`nature-writing` 对应用于投稿的论文稿件。

版本、来源、修改和许可证索引见[仓库来源清单](../../../../SOURCES.md#nature)。许可证原文随包保存。
